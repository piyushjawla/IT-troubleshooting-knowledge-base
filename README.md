# IT Troubleshooting Knowledge Base

A growing collection of real-world troubleshooting scenarios, lab experiments, and system administration investigations documented while practicing IT support, networking, virtualization, and cybersecurity concepts.

The purpose of this repository is to improve troubleshooting methodology, documentation habits, and operational understanding of Windows, Linux, networking, virtualization, and endpoint systems.

Topics include:
- DNS troubleshooting
- Virtual machine networking
- Linux administration
- Windows troubleshooting
- Android/ADB recovery
- Virtualization issues
- Networking diagnostics
